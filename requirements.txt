# Library pins only. A notebook server is what these run in, so jupyterlab and
# ipywidgets are installed alongside this file rather than from it.
#
# Optuna arrives through the tune extra and used to arrive unpinned, which made
# the search notebook's committed numbers a function of the day the image was
# built rather than of the seed beside them: 4.9.0 to 5.0.0 moved every printed
# result at an unchanged seed, and a reader comparing their run against the page
# has no way to see that. It is pinned here rather than in emsl, because a
# library that pinned its own sampler would force that version on every caller.
#
# Gymnasium is a dependency of emsl rather than an extra, which is why it is
# not listed. Torch is not listed either: the Dockerfile installs the CPU build
# before this file is read, so resolving sb3 finds it already satisfied rather
# than pulling the CUDA wheel from PyPI.
